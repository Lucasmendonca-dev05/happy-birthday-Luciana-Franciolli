Site estático (HTML/CSS/JS). Hoje mostra "em breve" + contagem regressiva (festa às 17h).

## No dia de publicar as fotos
1. Coloque as fotos editadas (JPG, ~2500px no lado maior) em `photos/`. Elas são o que a pessoa baixa.
2. `npm install` (só na primeira vez) e depois `npm run fotos` — cria as miniaturas em `photos/thumbs/` e o `photos/photos.json`.
3. Em `config.js`: `galleryOpen: true` e seu nome em `photographer`.
4. Commit + push.
