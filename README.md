Site estático (HTML/CSS/JS). Hoje mostra "em breve" + contagem regressiva.

## No dia de publicar as fotos
1. Coloque as fotos editadas (JPG/WebP, ~2000px no lado maior) em `photos/`.
2. `node tools/gen-photos.js` (gera `photos/photos.json`).
3. Em `config.js`: `galleryOpen: true` (e `zipFile` se tiver um .zip).
4. Commit + push.
